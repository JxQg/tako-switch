## 3. 边界与澄清确认

1. **IEEE-754 浮点除法精度边界（`toPlazaCNY(1.2)` 与 `channelRatioToOfficialMultiplier(2.04)`）**：
   - 规格 §3.1 定义 `toPlazaCNY(internalUSD) -> internalUSD / 3`。在 JavaScript IEEE-754 双精度浮点运算中，`1.2 / 3 === 0.39999999999999997`（与字面量 `0.4` 存在 `5.55e-17` 尾差），而经 `formatPlazaMoney(1.2)` 格式化后精确输出 `"¥0.4"`。因此黑盒脚本对纯数值返回采用 `< 1e-12` 容差断言，对格式化字符串采用严格字面量 `===` 断言。
2. **限时特惠截止日当天边界（`2026-11-30`）**：
   - 规格 §1 注明「截至 `2026-11-30` 展示 `🔥 限时半价 · 11-30`」，§2.3 写「在 `2026-11-30` 前返回 `Some("2026-11-30")`」。常规自然日截止语义为含当日（`date <= "2026-11-30"` 有效，`"2026-12-01"` 失效）；自动化断言聚焦规格明确指定的有效日 `"2026-11-22"` 与失效日 `"2026-12-01"`，截止日当天闭合性在合并验收时一并核验。
3. **独立即时汉化在原无配置文件时的清理一致性**：
   - 当客户端处于 `Official` 模式且原本不存在配置文件（如新建沙盒下无 `~/.codex/config.toml`、`~/.codex/AGENTS.md`、`~/.gemini/AGENTS.md`）时，执行 `sync_standalone_chinese_locale(&paths, true)` 再执行 `sync_standalone_chinese_locale(&paths, false)` 后，`is_chinese_configured(&paths)` 必须回到 `false`，且不应遗留含受控块或中文覆盖键的脏配置。
4. **ASAR `OutdatedAfterUpgrade` 下还原操作的返回语义**：
   - 规格 §2.1 明确规定在 `OutdatedAfterUpgrade` 状态下调用还原时「不得用旧版 `app.asar.orig` 降级覆盖新版客户端，仅清理过期的 `patch-meta.json` 并返回 `Unpatched`」。测试重点断言 `restore_antigravity_ui_for_paths` 返回 `Ok(...)`、磁盘新版 `v2.2.0` `app.asar` 与 `Info.plist` 字节零改动、且后续 `inspect_antigravity_ui_patch` 状态变为 `UiPatchStatus::Unpatched`。
