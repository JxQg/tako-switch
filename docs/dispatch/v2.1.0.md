# Tako Switch v2.1.0 交付说明

> 目标版本：`v2.1.0`
> 主题：**Claude Desktop 全量简体中文界面汉化（双 ASAR）+ 跨平台权限引导与配置/补丁解耦**

---

## 1. 核心交付内容

### 1.1 Claude Desktop 纯 Rust 双 ASAR 简体中文补丁器（`src-tauri/src/adapters/claude_i18n.rs`）
- **双资源包同步修补**：
  - `Resources/app.asar`：注入 `__tako_i18n_patch.json` 标识，在 `.vite/build/*.js` 启用 `"zh-Hans"` / `zh` 映射并放宽 `sHe()` 文件名正则（兼容 `zh-Hans.json` 与 `es-419.json`），保留原厂 `resources/i18n/zh-Hans.json` 译文并补齐缺失的 8 条浏览器/自动更新词条。
  - `Resources/ion-dist.asar`：向前端 11 语言白名单数组追加 `"zh-Hans"`，在语言显示表添加 `中文（简体）` 词条，生成 51 词条全中文 `i18n/dynamic/zh-Hans.json` 以及与 `i18n/en-US.json` 100% 键对齐的 `i18n/zh-Hans.json`。
- **ICU 占位符与富文本标签强门禁（`validate_icu_compatibility`）**：
  - 严格校验 `{}` 括号平衡、顶层及 `plural`/`select`/`selectordinal` 嵌套占位符变量名集合、格式类型与成对 XML/HTML 富文本标签（`<a>`/`<link>`/`<kbd>` 等），任何不匹配译文自动回退原文，杜绝 `react-intl` 运行时崩溃。
- **macOS 与 Windows 完整性及无损还原**：
  - macOS：同步更新 `Info.plist` 中 `Resources/app.asar` 与 `Resources/ion-dist.asar` 双完整性哈希，受控备份至 `~/.tako/switch/backups/claude/ui_patch/`（含 `MacOS_Claude.orig` 与 `CodeResources.orig`），支持 100% 字节级原厂还原与客户端自升级后的 `OutdatedAfterUpgrade` 安全检测（绝不以旧备份降级新版客户端）。
  - Windows：支持 Squirrel `app-<ver>` 数值语义降序定位、Electron FuseV1 完整性校验探测、PE32/PE32+ 内嵌哈希修补与 Authenticode 清理（`patch_windows_pe_asar_integrity`）、Microsoft Store (MSIX) `WindowsApps` 只读保护识别。

### 1.2 跨平台权限拦截分类、配置/ASAR 解耦与引导弹窗（`asar_patch.rs`, `lib.rs`, `main.rs`, `UiPatchPermissionModal.tsx`）
- 统一结构化错误协议 `[TAKO_UI_PATCH_BLOCK]<json>|<message>`，精确分类 `macos_app_management`、`windows_uac`、`windows_file_lock`、`windows_msix_read_only`。
- `apply_prefer_chinese_ui_for_paths` 先提交三端配置文件级简体中文（Codex / Claude 1p+3p+Claude Code / Antigravity），再执行 ASAR 界面补丁；若遇权限拦截则收集到 `DashboardPayload.uiPatchPrompts` 返回，**绝不回滚或阻断配置文件级汉化**。
- 前端为 Claude Desktop 与 Google Antigravity 提供统一的「界面汉化 / 还原原版 / 升级后重打汉化」入口，并在权限受限时弹出 `UiPatchPermissionModal`，提供一键打开 macOS「隐私与安全性 → App 管理」及重试按钮。
- `main.rs` 新增 `ui-patch-worker --app <claude|antigravity> --action <patch|restore>` CLI 子命令，配合 Windows 临时 UAC 提权执行。
