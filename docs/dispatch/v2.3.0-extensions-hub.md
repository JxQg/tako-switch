## 1. 全局合规红线与低版本升级兼容契约（全阶段强制遵守）

1. **纳管平台边界**：
   - 四个扩展模块统一且仅纳管 **`Claude` / `Codex` / `Antigravity` 三端**（序列化枚举固定为 `"claude" | "codex" | "antigravity"`）。
   - **严禁触碰 `~/.dsh-tako`** 下的任何配置或目录。
2. **零硬编码路径与沙盒可测性**：
   - 所有后端核心函数必须提供 `*_for_paths(paths: &AppPaths, ...)` 入口，从 `AppPaths` 派生全部读写路径，**严禁在业务逻辑中直接调用 `dirs::home_dir()` 或硬编码真实宿主机绝对路径**。
   - 所有单元/集成测试必须使用 `tempfile::TempDir` + `AppPaths::for_test(tmp.path())`（断言 `paths.is_test == true`），零污染宿主机真实 `~/.tako`、`~/.claude`、`~/.codex`、`~/.gemini`。
3. **原子落盘、首次备份与低版本平滑升级兼容**：
   - 中心持久化统一存放在 `~/.tako/switch/extensions/`（`paths.switch_dir().join("extensions")`）与 `~/.tako/switch/skills/`（`paths.switch_dir().join("skills")`），不引入 SQLite。
   - 全部文件写入必须通过 `crate::config::write_atomic` 执行原子替换；首次修改任何客户端原生文件前必须调用 `crate::config::backup_file_once` 留存备份。
   - 所有 JSON 持久化结构体字段必须标注 `#[serde(default)]`（及 `#[serde(rename_all = "camelCase")]`），当低版本（`<= v2.2.7`）升级后文件不存在或缺少新字段时平滑回退默认值，绝不报错崩溃。
   - **历史资产自动收编**：低版本用户升级后首次进入扩展中心时，自动无损扫描并收编三端已存在的第三方自定义 MCP、已有 Skills 目录及已有手写提示词文件（`CLAUDE.md` / `AGENTS.md`），严禁因中心库为空而覆盖或清空用户已有配置。
4. **网络代理策略一致性**：
   - 任何出网请求（Skills 仓库拉取、Antigravity `gstatic` 插件目录拉取）必须读取 `read_switch_state(paths).bypass_system_proxy`：为 `true` 时构建 `reqwest::Client::builder().no_proxy()`，为 `false` 时遵循系统代理。
5. **进程与 ASAR 安全铁律**：
   - 严禁执行 `pkill -x tako-switch` / `killall tako-switch` / `Stop-Process -Name tako-switch`。
   - Windows 下调用任何外部 CLI 子进程（如 `claude`、`codex`、`agy`）必须附加 `CREATE_NO_WINDOW (0x08000000)` 与 `Stdio::null()`，防止弹出控制台黑框或卡死等待交互输入。
   - 严禁在任何新增文件中出现未授权的 `app.asar` 字符串或外部 `@electron/asar` 调用（确保 `scripts/verify_client_mcp_ui.py` 反篡改检查 100% 通过）。
6. **主题自适应与 `720×560` 最小窗口零越界规范**：
   - **严禁硬编码浅色背景色值**（如 `#ffffff`、`#faf9ff`、`#fbfcfe`），必须 100% 使用 [`src/index.css`](../../src/index.css) 定义的 CSS 变量（`var(--bg-card)`、`var(--bg-subtle)`、`var(--bg-canvas)`、`var(--accent-soft)`、`var(--border)`、`var(--text-*)` 等），保证浅色/深色（`[data-theme="dark"]`）与紧凑/舒适（`[data-density="comfortable"]`）双密度完美呈现。
   - **顶栏单主按钮铁律**：扩展中心顶栏左侧为 4 项 `lucide-react` 线性矢量图标切换器 + `tabular-nums` 数量徽章（严禁混排 Emoji 造成基线位移），右侧**最多并列 1 个紧凑次级按钮（`更多 ▾` 或 `刷新`）+ 1 个主操作按钮**。
   - **弹性搜索框与 `?` 气泡收纳**：所有搜索框统一使用 `flex-1 min-w-[150px] max-w-[280px]`，内部 `<input>` 设置 `min-w-0 truncate`，placeholder 控制在 12 个汉字以内；冗长的路径与机制说明统一收纳至 `26×26` 的 `?` 按钮悬停/点击气泡中。
   - **表格与卡片 `min-w-0` 全覆盖**：所有网格首列标题、路径、描述均加 `min-w-0` + `truncate`，右侧开关与操作按钮强制 `shrink-0 whitespace-nowrap`。

### 3.3 Phase 3：三端 CLI 插件管理（`feat/ext-hub-phase3`）

1. **桌面端内置优先 CLI 探测器（`plugins.rs`）**：
   - 支持测试环境通过 `AppPaths` 或可选测试覆盖字段注入沙盒 CLI 路径，生产环境严格按 **「桌面端安装包内置路径优先 → 用户常用 CLI 目录 → 系统 `PATH` 回退」** 探测：
     - `Antigravity` (`agy`)：先查 `paths.agy_app_override_dir`、Windows `%LOCALAPPDATA%\Programs\Antigravity\bin\agy.cmd`、`%LOCALAPPDATA%\Programs\Antigravity\resources\app\bin\agy.cmd`、`C:\Program Files\Antigravity\bin\agy.cmd`、macOS `/Applications/Antigravity.app/Contents/Resources/app/bin/agy`、`~/Applications/Antigravity.app/Contents/Resources/app/bin/agy`，再回退 `PATH` 中的 `agy` / `agy.cmd`。
     - `Codex` (`codex`)：先查 macOS `/Applications/Codex.app/Contents/Resources/codex`、Windows `%APPDATA%\npm\codex.cmd`、`~/.cargo/bin/codex`，再回退 `PATH` 中的 `codex` / `codex.cmd`。
     - `Claude` (`claude`)：先查 `~/.local/bin/claude(.exe)`、`~/.claude/local/claude`、Windows `%APPDATA%\npm\claude.cmd`、`%LOCALAPPDATA%\Programs\claude\claude.exe`，再回退 `PATH` 中的 `claude` / `claude.cmd`。
   - **未检出 CLI 的优雅空状态**：当某端未检测到可用 CLI 时，快照返回 `cliAvailable: false, cliSource: null`，前端在 `PluginsHubView.tsx` 渲染干净居中的空状态卡片（`data-testid="ext-plugins-empty-unsupported"`）：**「未检测到对应 CLI，当前客户端暂不支持该功能」**，不弹错误 Toast，也不诱导用户去终端手动装包。

2. **三端插件操作与目录缓存契约**：
   - 参数安全校验：严格校验插件 ID（`name@marketplace` 或合法目录段，拒绝以 `-` 开头的参数防 CLI flag 注入）。
   - `Claude`：`plugin list [--available] --json`、`plugin install/uninstall/enable/disable/update <id>`、`plugin marketplace list --json`、`plugin marketplace add <source>`、`plugin marketplace remove <name>`；从 `installPath/.claude-plugin/plugin.json` 补全 `displayName` / `description` / `category`。

   - `Antigravity`：
     - 已安装列表执行 `agy plugin list --json`，并从 `~/.gemini/config/plugins/<dir>` 下的 `""` / `.antigravity-plugin` / `.gemini-plugin` / `.claude-plugin` 读取 `plugin.json`（支持剥离 JSONC `//`、`/* */` 注释与尾随逗号）补全展示信息；`enable` / `disable` / `uninstall` 传目录名 `<name>`。
     - 发现目录拉取官方 `https://www.gstatic.com/antigravity/plugins/marketplace.json`（`antigravity-plugins-official`）与合作伙伴 `https://www.gstatic.com/antigravity/plugins-partners/marketplace.json`（`antigravity-plugins-partners`），遵循 `bypass_system_proxy` 并缓存至 `~/.tako/switch/extensions/plugin_cache.json`；安装与原地更新执行 `agy plugin install <name>@<marketplace>`，若装完仍为停用态则返回 `needsConfiguration: true` 提示客户端内授权。
     - `Antigravity` 下 `marketplacesSupported = false`，前端「市场源」子页签与 `+ 添加市场` 自动置灰禁用。
   - 错误分类识别：识别目录被进程锁占用（`PLUGIN_IN_USE`）与需终端确认（`PLUGIN_NEEDS_TERMINAL_CONFIRM`），向用户展示清晰可操作的中文提示。
