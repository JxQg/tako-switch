### 1.1 `McpToolsConfig` 扩展（Rust `src-tauri/src/config.rs` & TS `src/lib/api.ts`）

Rust (`#[serde(rename_all = "camelCase")]`):
```rust
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct McpToolsConfig {
    #[serde(default = "default_true")]
    pub image: bool,
    #[serde(default = "default_true")]
    pub video: bool,
    #[serde(default = "default_true")]
    pub audio: bool,
    #[serde(default = "default_true")]
    pub search: bool,
    #[serde(default = "default_true")]
    pub consult: bool,
    #[serde(default)]
    pub web_page: bool,
    #[serde(default)]
    pub edgeone_api_token: Option<String>,
    #[serde(default)]
    pub edgeone_project_name: Option<String>,
    #[serde(default)]
    pub output_dir: String,
    #[serde(default)]
    pub consult_model: String,
}
```
- `web_page` 默认 `false`（按需开启，不强行要求未装 Node.js 的老用户立刻加载）。
- `edgeone_api_token` 与 `edgeone_project_name` 为可选，留空（`None` 或空串归一化为 `None`）时走腾讯云 EdgeOne 官方免密钥浏览器一键授权流程。
- 向后兼容：旧版 `state.json` 不含这三个字段时必须正常反序列化不报错。

TypeScript (`src/lib/api.ts`):
```ts
export interface McpToolsConfig {
  image: boolean;
  video: boolean;
  audio: boolean;
  search: boolean;
  consult: boolean;
  webPage?: boolean;
  edgeoneApiToken?: string | null;
  edgeoneProjectName?: string | null;
  outputDir: string;
  consultModel: string;
}

export interface NodeRuntimeInfo {
  available: boolean;
  version: string | null;
  major: number | null;
  meetsMinVersion: boolean;
  nodePath: string | null;
  npxPath: string | null;
}
```
Tauri 命令：`check_node_runtime` → `api.checkNodeRuntime(): Promise<NodeRuntimeInfo>`（检测本机 `node` / `npx` 及是否满足 `>= 18`）。

### 1.2 `Tako Web Page (EdgeOne)` MCP 注入规范

- Server 键名常量：`pub const EDGEONE_MCP_SERVER_KEY: &str = "tako-web-page";`
- 官方包与参数：`command: "npx"`（或检测到的绝对路径回退 `"npx"`），`args: ["-y", "@edgeone/makers-mcp@latest", "--region", "china"]`
- 环境变量 `env`（仅当对应配置非空时写入，留空则不写 `env` 字段）：
  - `EDGEONE_PAGES_API_TOKEN`（当 `edgeone_api_token` 非空）
  - `EDGEONE_PAGES_PROJECT_NAME`（当 `edgeone_project_name` 非空）
- 客户端同步规则：
  - **Claude Desktop**：`1p`/`3p` `claude_desktop_config.json` 的 `mcpServers["tako-web-page"]`（以及 `3p` `managedMcpServers` 或工具白名单不阻拦）随 `mode == Tako && state.mcp.web_page` 启用/移除；`Official` 模式或 `web_page == false` 时移除，且绝不破坏用户其它 `mcpServers`。
  - **Codex Desktop**：`~/.codex/config.toml` `[mcp_servers."tako-web-page"]`（`command`, `args`, 可选 `env` 表）随 `mode == Tako && state.mcp.web_page` 启用/移除；关闭或切回 `Official` 时清理干净。
  - **Google Antigravity**：`~/.gemini/antigravity/mcp_config.json` `mcpServers["tako-web-page"]` 随 `mode == Tako && state.mcp.web_page` 启用/移除。
  - **DSH Tako**：检查 `~/.dsh-tako` 是否有 `mcp.json` / `config.yaml` 等 MCP 配置支持；若 DSH Tako 当前不读外部 `mcpServers` JSON，则在 `adapters/dsh_tako.rs` 明确保持安全无破坏并记录在诊断备注中（不臆造不存在的配置文件）。
  - **`save_settings` 联动**：当 `mcp.web_page` / `mcp.edgeone_api_token` / `mcp.edgeone_project_name` 变更时，自动对当前处于 `AppMode::Tako` 的客户端重新同步配置，无需用户手动切一次模式。

### 1.3 Antigravity 全量简体中文汉化引擎规范（`antigravity_i18n.rs` + `antigravity_zh_dict.json`）

- 将原本内联在 `antigravity_i18n.rs` 中的 229 条手写词典抽离为独立 JSON 文件 `src-tauri/src/adapters/antigravity_zh_dict.json`（与 `claude_zh_dict.json` 同结构），通过 `include_str!("antigravity_zh_dict.json")` 编译期嵌入。
- 词典规模与质量要求：
  - 有效词条数 `>= 1,200` 条，覆盖 Antigravity 2.x 全界面：侧边栏与对话管理、Chat Canvas / Composer / 模型与推理强度、Skills & Customizations / Rules / Workflows / Plugins / MCP Servers、Scheduled Tasks、Settings（General / Account / Appearance / Permissions / Sandbox / Allowlist / Browser / Editor / Shortcuts / Updates / About）、Subagents / Swarm / Background Tasks / Artifacts / Diff / Terminals / Remote SSH / Browser Viewer / 弹窗确认与报错提示 / 原生菜单与托盘。
  - 所有词条必须为非空自然中文（允许保留 `MCP`、`SSH`、`API`、`Git`、`Diff`、`URL`、`JSON`、`Antigravity`、`Claude`、`Codex`、`Gemini`、`Tako` 等通用专词）。
- 运行时翻译引擎升级（`dist/preload.js` 注入脚本）：
  - **精确词典查表**（含自动去除末尾 `:` / `...` / `…` 后的二次命中，并保留标点后缀）；
  - **动态模板正则规则（`DYNAMIC_RULES`）**：至少覆盖 `Thinking for <duration>`、`Thought for <duration>`、`N files changed`、`N file changed`、`N lines added/removed`、`Nm/Nh/Nd/Ns ago`、`Step N of M`、`N tools` / `N conversations` / `N tasks` / `N servers`、`Showing lines A-B of C`、`Running <cmd>` / `Edited <n> files` 等高频动态 UI 文案；
  - **Shadow DOM 与同源 `iframe` 支持**：遍历开放 `el.shadowRoot` 及同源 `iframe`（带 `try/catch` 安全隔离，保留 `127.0.0.1` / `localhost` 校验）；
  - **严格安全跳过（绝不误翻代码与聊天正文）**：跳过 `SCRIPT`/`STYLE`/`CODE`/`PRE`/`TEXTAREA`/`INPUT`/`KBD`/`SAMP`/`SVG`/`MATH`、`contenteditable`、`.monaco-editor`、`.xterm`、Markdown 聊天消息正文容器（带合理长度上限与安全 class/role 判断），防止误伤代码片段和用户对话。
  - **补丁版本升级感知与字节级无损还原**：保留 `app.asar.orig`、`original_asar_sha256`、`verify_clean_backup_asar`、`restore_antigravity_ui_for_paths` 100% 字节级还原；保留 `PATCH_GUARD_COMMENT`（或升级为 v2 兼容检测，确保幂等）。

### 1.4 前端极简重设计规范（Opus 高保真方案落地）

- **三域信息架构**：
  - 左侧固定导航（宽度 `220px`，避免 `Claude Desktop` / 状态短标签折行）：
    - 上段「全局」：`总览`（轻量四端概览 + 一键全部更新/一键三端汉化）、`通用设置`、`MCP 能力`
    - 下段「软件独立设置」：`Claude Desktop`、`Codex`、`Antigravity`、`DSH Tako`（单行品牌图标 + 名称 + 紧凑状态短标签 `Tako` / `官方` / `同步` / `未装`）
  - 顶部极简标题栏：左侧窗口标题，右侧 `网关运行中` 指示点 + 余额短显（已登录时） + 账号头像/登录入口（点开可快速查看配额或跳通用设置）。
  - 右侧面板单域呈现，杜绝「首页同时堆 4 张超长客户端卡 + 内联剧场 + 多排设置」：
    - **软件独立设置面板**：页头（软件名 + 打开/重启主操作）→ 三项状态摘要卡（安装版本 / 运行模式 / 更新）→ 专属汉化状态带（Claude Desktop & Antigravity 顶部单一开关 + 次级「还原原版」）→ 连接与模型（运行模式分段切换 + 可用模型按钮 + 软件独有项：Codex 保留官方登录 / Claude 网关副标题 / Antigravity 专用 Key & 32 槽位 / DSH Tako 同步模式）→ 安装与维护（安装/升级/关闭/诊断按需折叠）。
    - **通用设置面板**：账号与余额卡 → 网关与网络（本地统一网关、绕过系统代理、显示名称）→ 更新策略（启动检查、Switch 自更新、客户端集中检查、更新日志）→ 外观与菜单栏（浅色/深色/跟随系统、菜单栏余额）→ 高级折叠（服务地址、Manifest 源、媒体输出目录、反馈入口）。
    - **MCP 能力中心面板**：顶部横跨全宽卡片 **「网站上线 · Tako Web Page」**（默认浏览器一键授权发布到腾讯云 EdgeOne，主开关 `data-testid="mcp-toggle-webpage"`，右侧「查看授权流程」说明弹窗，下方折叠「高级：Token 与项目名」+ 本机 Node.js >= 18 状态提示）+ 下方 2 列 5 项核心能力卡（图像生成、视频生成、声音生成、联网搜索、多模型会诊，每卡仅含图标 + 标题 + 一句话描述 + 开关 + `体验能力 →` 按钮）；点击 `体验能力 →` 打开侧滑抽屉/弹窗展示 `McpInlineTheater`（保留所有已有 `data-testid`）。
- **必须保留的已有核心 `data-testid` 与能力**：
  - 保留 `verify_client_mcp_ui.py` 中的关键 `data-testid`（或按新交互同步更新，确保 `main-chinese-ui-toggle`、`open-model-square-btn`、`agy-ui-patch-btn`、`agy-ui-restore-btn`、`claude-ui-patch-btn`、`ui-patch-permission-modal`、`open-mcp-demo`、`mcp-inline-theater`、`mcp-demo-tab-*`、`plaza-*` 等关键入口全部真实可交互）。
  - 品牌图标去重包装：移除 `BrandIcons.tsx` 冗余的白底 + 边框 + 阴影三层容器，普通设置行不加装饰图标。
