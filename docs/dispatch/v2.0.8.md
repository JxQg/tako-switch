# Tako Switch v2.0.8 研发派工与双工作树隔离契约

## 1. 工作树与职责分离

`v2.0.8` 采用「独立开发工作树 + 独立黑盒测试工作树」双轨物理隔离模式，由主控协调器（Coordinator）统一冻结规格并合并验收：

| 角色 | 专属 Git Worktree | 分支名 | 职责边界 |
|---|---|---|---|
| 开发工程师（Dev Subagent） | `/tmp/tako-switch-wt-dev-208` | `feat/v2.0.8-i18n-and-plaza` | 依据冻结规格完成 Rust 后端、React/TS 前端、静态门禁脚本更新、版本号升级（`2.0.8`）及全套自检提交。 |
| 测试工程师（Test Subagent） | `/tmp/tako-switch-wt-test-208` | `test/v2.0.8-blackbox` | 仅依据规格契约独立编写黑盒测试计划、沙盒集成测试（ASAR 补丁/升级/还原、三端独立中文同步、模型广场定价与筛选）与浏览器 UI 验收。 |
| 主仓（只读保护） | `/Users/bytedance/develop/tako-switch-v2` | `main` | 开发与测试子智能体严禁直接修改主仓、严禁私自 `git push` 或打 `git tag`。 |

### 宿主机与进程安全铁律
1. 单测与集成测试一律使用 `AppPaths::for_test(temp_dir)`（`is_test = true`）及 `agy_app_override_dir` 临时沙盒目录，**严禁触碰**宿主机 `/Applications/Antigravity.app`、`~/.codex`、`~/.claude`、`~/.gemini`、`~/.tako` 或在 `is_test == true` 时调用真实 `/usr/bin/codesign`、`/usr/bin/defaults`。
2. **严禁执行** `pkill -x tako-switch` 或 `killall tako-switch`，避免误杀宿主机正在承载会话的 `tako-switch mcp-server` 与 `gateway-proxy` 守护进程。
3. 严禁触碰宿主机 `8790` 端口无关服务。

## 2. 冻结公开接口契约摘要

### 2.1 Rust 后端公开符号
- `tako_switch_lib::config::AppPaths`：新增 `pub agy_app_override_dir: Option<PathBuf>`（默认 `None`）。
- `tako_switch_lib::adapters::antigravity_i18n`（同步由 `adapters` 重导出）：
  - `UiPatchStatus::{NotApplicable, NotInstalled, Unpatched, Patched, OutdatedAfterUpgrade, Unsupported}`（`snake_case`）
  - `UiPatchInfo { status, patch_version, has_valid_backup, target_asar_path, note }`（`camelCase`）
  - `inspect_antigravity_ui_patch(paths: &AppPaths) -> UiPatchInfo`
  - `patch_antigravity_ui_for_paths(paths: &AppPaths) -> Result<UiPatchInfo, String>`
  - `restore_antigravity_ui_for_paths(paths: &AppPaths) -> Result<UiPatchInfo, String>`
- 三端独立即时汉化：
  - `CodexAdapter` / `ClaudeAdapter` / `AntigravityAdapter` 均提供 `sync_standalone_chinese_locale(paths: &AppPaths, enable: bool) -> Result<(), String>` 与 `is_chinese_configured(paths: &AppPaths) -> bool`。
  - `AppSnapshot` 新增 `chinese_configured: bool` 与 `ui_patch: UiPatchInfo`。
- 模型广场公开接口（`tako_switch_lib::agy_proxy`）：
  - `ClientModelOption` 新增 `cache_usd_per_m`、`quota_type`、`model_ratio`、`official_multiplier`、`promo_ends_on`、`capabilities`、`tags`、`vendor_name`。
  - `build_plaza_model_options(pricing_body: &Value, perf: &HashMap<String, ModelPerfInfo>) -> ClientModelsResponse`
  - `fetch_plaza_models_for_ui(paths: &AppPaths) -> Result<ClientModelsResponse, String>`
- 新增 Tauri Commands（`src-tauri/src/lib.rs`）：
  - `set_prefer_chinese_ui(app, enable, patch_antigravity, auto_restart)`
  - `patch_antigravity_ui(app, auto_restart)`
  - `restore_antigravity_ui(app, auto_restart)`
  - `list_plaza_models()`

### 2.2 前端模块与必选 `data-testid`
- 定价纯函数库：`src/lib/plaza-pricing.ts`（`PLAZA_INTERNAL_USD_PER_CNY = 3`、`OFFICIAL_PRICE_RATIO_BASE = 20.4`、`toPlazaCNY`、`formatPlazaMoney`、`channelRatioToOfficialMultiplier`、`formatMultiplier`、`formatZhe`、`matchesPlazaQuickFilter`）。
- 主界面必选 `data-testid`：`main-chinese-ui-toggle`、`open-model-square-btn`、`agy-ui-patch-btn`、`agy-ui-restore-btn`（保留全部存量 MCP 内联剧场 `data-testid` 与设置页 `PREF_CHINESE_SUBTITLE`）。
- 模型广场弹窗必选 `data-testid`：`plaza-price-mode-detail`、`plaza-price-mode-avg`、`plaza-currency-cny`、`plaza-currency-usd`、`plaza-unit-m`、`plaza-unit-k`、`plaza-quick-all`、`plaza-quick-promo`、`plaza-quick-cheap`、`plaza-quick-code`、`plaza-quick-long`、`plaza-quick-image`。

## 3. 提交门禁清单

1. `npm run typecheck && npm run build`
2. `cargo test --manifest-path src-tauri/Cargo.toml`
3. `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`
4. `python3 -m unittest -v scripts/test_sync_manifest.py`
5. `python3 scripts/verify_client_mcp_ui.py --self-test && python3 scripts/verify_client_mcp_ui.py`
6. `cmp -s CLAUDE.md AGENTS.md` 字节完全一致，且 `package.json`、`package-lock.json`、`src-tauri/tauri.conf.json`、`src-tauri/Cargo.toml` 版本号统一为 `2.0.8`。
